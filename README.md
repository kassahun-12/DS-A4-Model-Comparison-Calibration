This project presents a reproducible comparison of four machine-learning approaches for fingerprint verification: a prior-probability baseline, logistic regression, random forest, and histogram-based gradient boosting. The workflow extracts image-pair similarity features and evaluates the models using identity-grouped five-fold splits, ROC-AUC, average precision, Brier score, calibration plots, and cluster-bootstrap confidence intervals. It also includes threshold cost-sensitivity analysis, human-review capacity scenarios, dataset-level performance slices, and an examination of model failure cases.

In the preliminary pooled out-of-fold evaluation, histogram-based gradient boosting achieved the highest ROC-AUC (0.7523), followed closely by logistic regression (0.7437) and random forest (0.7243). The bootstrap confidence intervals were wide and overlapping, so the results do not establish a reliable performance advantage for one model. The analysis also reveals substantial false-rejection rates at the illustrative 0.5 threshold, highlighting the importance of threshold selection and error-cost trade-offs.

The study is exploratory rather than deployment-ready. The dataset contains only 20 dataset-specific identities, impostor-pair coverage is incomplete, and the test-pair genuine-match proportion differs from the training proportion. Threshold analysis and simulated review benefits therefore require independent validation before operational use. The repository includes the notebook, frozen protocol, documentation, aggregate results, plots, dependency information, and AI-use log.
